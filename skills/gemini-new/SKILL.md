# Start New Google Gemini Thread

Start a fresh Google Gemini thread for the current repo and branch:

```bash
gemini-review reset
```

Inform the user that the previous Gemini conversation mapping has been reset, and the next `gemini-review` will begin in a brand-new Gemini thread.
