# Start New ChatGPT Thread

Start a fresh ChatGPT thread for the current repo and branch:

```bash
chatgpt-review reset
```

Inform the user that the previous conversation mapping has been reset, and the next `chatgpt-review` will begin in a brand-new ChatGPT thread.
