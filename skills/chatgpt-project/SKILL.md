# ChatGPT Project Management

Manage the ChatGPT Project associated with this repository:

- `chatgpt-review project list` — list all ChatGPT Projects
- `chatgpt-review project resolve` — get the project mapped to this repo
- `chatgpt-review project attach <name>` — map this repo to an existing project
- `chatgpt-review project detach` — disconnect project mapping for this repo
- `chatgpt-review project create <name>` — create a new project on ChatGPT Web

Run the requested action and summarize the result for the user.
